# Sources

- Public Suffix List: https://publicsuffix.org/list/public_suffix_list.dat, fetched October 1, 2026. MPL 2.0; license notice remains in the bundled file.
- SafariConverterLib 4.3.0: https://github.com/AdguardTeam/SafariConverterLib. GPL 3.0. Its transitive packages are managed by SwiftPM.
- AdGuard Scriptlets 2.3.1: the exact official npm package is pinned in `Vendor/AdGuardScriptlets-2.3.1/npm-package.tgz`; its full source at tag v2.3.1, commit `c75c18fd95de614c733d9db285fb0daa9835028b`, is preserved in `source.tar.gz`. The bundled dependency-free catalog is losslessly compressed and checked against its original SHA-256 before injection. `Iris/Resources/YouTubeScriptlets/LICENSE.txt` and `NOTICE.txt` preserve its GPL-3.0 license and attribution. The final ESM export declaration is removed only in memory when wrapping the catalog; the vendored original remains intact. No runtime library downloads or updates occur. See the vendor README for provenance and reproduction.

The pinned Scriptlets package's [license](https://github.com/AdguardTeam/Scriptlets/blob/v2.3.1/LICENSE) is GPL-3.0, not a permissive license. This was reported to Max before bundling. Personal headset use is permitted; this pilot does not establish App Store licensing clearance. A future closed-source App Store release needs suitable commercial licensing or replacement of both Scriptlets and the existing GPL SafariConverterLib. AdGuard's [licensing statement](https://adguard.com/en/eula.html) lists these libraries as dual-licensed, but no commercial license was obtained in this session. GPL source/distribution obligations and Apple's distribution terms need review before publishing. Iris's own repository license has not been changed.
- Filter source URLs were checked against https://github.com/gorhill/uBlock/blob/master/assets/assets.json on October 1, 2026. EasyList and EasyPrivacy use the uAssets canonical mirrors listed there. Peter Lowe's canonical hosts list is translated into ABP network rules. Weekly downloaded list files retain their notices. The bundled offline snapshot contains the same seven sources, converted with SafariConverterLib 4.3.0 and `advancedBlocking: false`; `Iris/Resources/BlockingSnapshot/NOTICE.txt` preserves source URLs/notices and `Sources/*.txt.lzfse` contains each complete corresponding source with its original headers. `Scripts/update-filter-snapshot.sh` regenerates it using Iris's existing converter. JSON shards and full sources use Apple's lossless LZFSE compression, with SHA-256 verification of every decompressed rule shard. WebKit compiles the bundled JSON once on device; no private binary-cache format is copied.
- Safari content-rule exceptions apply within each compiled list, not across lists. A final separate `iris-allow` list cannot disable other shards. Iris instead removes/reattaches rules on each web view before main-frame navigation and reloads affected sites when toggled. Filter-list exception/control rules are repeated in every converter input shard. https://github.com/AdguardTeam/SafariConverterLib#safari-affinity

Apple APIs checked: WKPreferences.isElementFullscreenEnabled, WKWebView.callAsyncJavaScript, WKWebView.createWebArchiveData, AVURLAssetHTTPUserAgentKey, public WKContentRuleListStore compilation/lookup and NSData LZFSE compression/decompression. Xcode 27 and visionOS 27 are now installed and validated; see VALIDATION.md.
